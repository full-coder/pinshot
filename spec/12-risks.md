# 12 · 风险与缓解

按「会不会让项目做不成」排序。

## 1. 平台权限（高）

| 风险 | 后果 | 缓解 |
| --- | --- | --- |
| macOS 屏幕录制权限被拒 | 完全不可用 | 首次运行即引导；`doctor` 可自检；不得静默失败 |
| macOS 辅助功能权限（自动滚动必需） | 自动滚动不可用 | 只在用户点「自动滚动」时申请；拒绝则直接进手动模式 |
| TCC 授权后需重启进程 | 用户以为没生效 | 明确提示「已授权，请重新打开 PinShot」，并自动重启（可选） |
| Windows 代码签名证书缺失 | SmartScreen 拦截 | 先发布未签名 + 说明；M7 解决 |
| Linux Wayland 无窗口级捕获 | 功能缺失 | 明示不支持，自动关闭相关入口，而不是给出坏结果 |

## 2. 滚动截屏的技术风险（高）

| 风险 | 后果 | 缓解 |
| --- | --- | --- |
| 页面用 canvas/WebGL 渲染，滚轮注入无效 | 自动模式失败 | 手动模式兜底；探测式容器检测 |
| 页面有强动画/视频 | 相关性骤降 | 固定行/列掩码 + 列带投票 + 置信度阈值；宁可不拼 |
| 无限滚动 + 自动加载 | 永远滚不完 | `max_height` / `max_frames` 硬上限 |
| 滚动步长大于内容区，出现无重叠 | 丢内容 | 步长限制 ≤ 0.85 × 视口；`NoOverlap` 明确报错 |
| 亚像素滚动（高分屏 + 缩放） | 1px 级错位累积 | 只做整数像素；接缝检测 + 提示 |
| 8× 降采样丢信号 | 错误位移 | 金字塔封顶 4×（已实测验证） |

**总策略：宁可少拼一屏，不可产出未标注的错位长图。** 任何低置信度都必须走降级路径，
而不是"看起来差不多就输出"。

## 3. 排期风险（中高）

| 风险 | 后果 | 缓解 |
| --- | --- | --- |
| 标注"手感"打磨无止境 | 无限延期 | 门禁只认可测项；手感靠 M3 的 3 天自用 |
| Windows 后端无法在本机验证 | M5 延期 | 先用官方示例验证 API 可用性；不阻塞 macOS 主线 |
| 基准集制作被低估 | M4 无法验收 | 第 5 周开始录制，与 M3 并行 |
| 一个人做三平台 | 全平台都半成品 | 先把 macOS 做完整，Windows/Linux 明确标 beta |

## 4. 产品质量风险（中）

| 风险 | 后果 | 缓解 |
| --- | --- | --- |
| 贴图窗口太多导致内存暴涨 | 系统卡顿 | LRU + 缩略图常驻；上限提示 |
| 剪贴板大图（100 MB PSD） | 贴图时卡死 | 超过 64 MB 拒绝并提示 |
| 历史无限增长 | 磁盘满 | 三重保留策略 + 启动检查 |
| blob 与索引不一致 | 空白图 | 写入顺序固定（blob 先落盘）；`doctor --check-storage` |
| 全局热键与其他软件冲突 | 用户以为坏了 | 注册失败立即提示并引导改键 |

## 5. 生态与法务（中）

| 风险 | 后果 | 缓解 |
| --- | --- | --- |
| 与 Snipaste 界面过于相似 | 观感争议 | 交互范式（F1 截图、F3 贴图）属功能范畴，可参考；视觉与命名完全自研 |
| 名称 `PinShot` 商标冲突 | 需改名 | 发布前检索；改名成本已控制在三处 |
| 图标/字体版权 | 下架 | 图标自绘；字体只用系统字体 |
| 录屏类权限被系统收紧（未来 macOS） | 功能受限 | 关注 ScreenCaptureKit 的替代路径（如系统截图 API） |

## 6. 明确的技术债（先记账，不现在还）

| 债 | 何时还 |
| --- | --- |
| 只支持隐式滚动（不做 `scroll-behavior: smooth` 的动画预测） | 有真实用户反馈后 |
| 2D 拼接是"先纵后横"的简化实现 | M5 |
| 不做跨设备同步 | 永久不做 |
| 迁移框架只支持顺序升级 | 出现第一个破坏性变更时 |
| Linux 只支持 X11 | 按用户量决定 |

## 7. 放弃条件

如果出现下面任一情况，应缩小范围而不是硬撑：

1. **macOS 上的滚动截屏成功率 < 60%**（基准集）→ 砍掉自动模式，只保留手动，
   并把定位改成「连续的截图序列 + 一键拼接」（诚实且仍然有用）。
2. **标注的基本手感做不过系统自带截图**（M3 自用 3 天内 > 5 次想换回）→ 停止功能扩张，
   只打磨已有部分。
3. **每周可投入时间 < 15 小时** → 砍掉 Windows/Linux，只做 macOS 单平台。
