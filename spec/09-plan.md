# 09 · 计划

14 周，8 个里程碑。每个里程碑有**可执行门禁**：不通过就不进入下一个。
原则是「先把日常路径做通，再把长图做神」，因为长图只占 10% 的使用次数，
但如果日常截图不好用，用户根本不会留到用长图那一次。

## 总览

| 里程碑 | 周 | 主题 | 交付 | 门禁 |
| --- | --- | --- | --- | --- |
| M0 | 1 | 骨架 + 冻帧 + 复制 | 能截一张图进剪贴板 | G0 |
| M1 | 2–3 | 选区 + 标注 | 能标注并导出 | G1 |
| M2 | 4 | 贴图 | 贴图窗口全功能 | G2 |
| M3 | 5 | 历史 / 设置 / 托盘 / 热键 | **v0.1 可日常替代** | G3 |
| M4 | 6–8 | 滚动截屏 v1 | 自动 + 手动 + 拼接 | G4 |
| M5 | 9–10 | 滚动截屏 v2 | 窗口级 / 懒加载 / 2D | G5 |
| M6 | 11–12 | 打磨：OCR、取色卡片、二次编辑 | v0.4 | G6 |
| M7 | 13–14 | 发布：签名、更新、稳定性 | **v1.0** | G7 |

## M0 · 骨架与冻帧（第 1 周）

**做**

- Cargo workspace：`pinshot-core` / `capture` / `annnotate`(空壳) / `store` / `app` / `cli`。
- `src-tauri` 壳 + 一个全屏透明覆盖层窗口（`decorations: false`, `alwaysOnTop`）。
- macOS `CaptureBackend`：`SCScreenshotManager` 抓全屏 → RGBA → 覆盖层显示。
- 覆盖层显示冻帧（`ImageBitmap` + `drawImage`），Esc 退出、Esc 后前台 app 不变。
- 拖框选区（先只画遮罩与尺寸标签）。
- `Enter` → PNG → 系统剪贴板。

**门禁 G0**

- 三屏环境：覆盖层在三块屏上都正确，进入 ≤ 100 ms（p95，100 次）。
- 截一张 5120×2880 图 → 粘贴到备忘录，像素尺寸一致。
- 连续 20 次进入/退出截图，无内存增长（< 5 MB）。

## M1 · 选区与标注（第 2–3 周）

**做**

- 选区：8 把手、移动、`WASD`/方向键微调、`Ctrl+A` 全屏、`R` 上一次区域、尺寸读数。
- 放大镜：8×，显示坐标 + RGB/Hex，`Alt` 召唤，`C` 复制颜色。
- 标注：矩形/椭圆/直线/折线/箭头/画笔/记号笔/马赛克/模糊/文字/橡皮。
- 撤销重做、线宽、调色板、工具条（位置随选区自适应）。
- 导出：剪贴板 / 保存 / 快捷键保存。

**门禁 G1**

- 每种形状导出后像素正确（视觉回归 5 张基准图）。
- 100 步撤销后场景与初始逐字段相等。
- 5K 底图上画笔笔迹 p95 ≤ 16 ms。
- 马赛克区域原始像素不可恢复（块内方差 < 1）。

## M2 · 贴图（第 4 周）

**做**

- `PinManager` 状态机：`Visible / Hidden / Closed / Destroyed` + 可恢复队列。
- 窗口属性：无边框、置顶、不抢焦点、透明度、拖拽、缩放、旋转、翻转、缩略图、穿透。
- 剪贴板五类内容解析（图/文件/颜色/文本/HTML）。
- 右键菜单、分组、`Shift+F3` 隐藏全部。
- 全局热键 `F3` / `Shift+F3`。

**门禁 G2**

- 语义测试全绿：关闭可恢复、超额销毁、隐藏不影响计数、退出时 Closed 销毁而 Hidden 保留。
- 20 张 4K 贴图：拖动 60 fps，常驻内存 ≤ 300 MB。
- 从剪贴板到贴图可见 ≤ 120 ms。

## M3 · 日常可用（第 5 周）

**做**

- 历史面板（网格 + 时间分组 + 来源 app），`pinshot.db` + blob 落地。
- 截图中 `,` `.` 回放历史。
- 设置窗口（热键、截图、滚动、历史、导出、通用）。
- 托盘：左键截图、中键贴图、右键菜单。
- 权限引导（屏幕录制 / 辅助功能），`pinshot doctor`。
- 开机启动、多屏 + 混合 DPI 打磨。

**门禁 G3（关键）**

- **作者本人连续 3 天只用 PinShot 截图**，记录每次"想用别的工具"的瞬间。
- 冷启动到托盘 ≤ 400 ms；常驻内存 ≤ 60 MB。
- 混合 DPI（2x + 1x）双屏：选区跨屏导出无错位。

## M4 · 滚动截屏 v1（第 6–8 周）

**做**

- 第 6 周：容器定位（AX / 探测 / 兜底）、手动模式（连续抓帧 + 实时预览）。
- 第 7 周：自动模式（滚轮注入 + 稳定检测）、拼接（已有内核接入）、停止条件。
- 第 8 周：降级路径、接缝提示、长图进入标注、基准集 20 页跑分。

**门禁 G4**

- 20 页基准集：自动成功率 ≥ 16/20，总成功率（含手动降级）≥ 19/20。
- 位移误差 ≤ 1 px；无未标记的接缝错误。
- 12000 px 页面计算耗时 ≤ 400 ms（已由内核实测 166 ms，留抓帧余量）。

## M5 · 滚动截屏 v2（第 9–10 周）

**做**

- 窗口级捕获（SCK `desktopIndependentWindow` / WGC `CreateForWindow`）。
- 懒加载稳定检测、固定行/列增强（多列带投票）、吸底工具栏处理。
- 2D / 横向拼接（先纵向分块，再按行拼接横向）。
- 原始帧保留与"导入帧序列重跑"（`pinshot scroll --frames <dir>`）。
- Windows 后端接入（WGC）。

**门禁 G5**

- 遮挡窗口 50% 的页面，窗口级长图无遮挡。
- 懒加载图库页面：长图无空白块。
- 宽表格横向拼接正确（列对齐误差 ≤ 1 px）。

## M6 · 打磨（第 11–12 周）

**做**

- 序号标注、裁剪、二次编辑（选中/移动/改色）。
- 取色卡片与颜色历史、`Shift` 切换 RGB/Hex/HSL。
- OCR（mac Vision / Win OCR），结果进历史并可搜索。
- 窗口/元素识别（`Tab` 切换），父/子元素逐级选择。
- Linux X11 后端。

**门禁 G6**

- OCR 中英混排 10 张样本，可复制率 100%，字符准确率 ≥ 95%。
- 二次编辑：选中形状后拖动，撤销可完整回退。
- Linux X11 上全屏截图 + 手动滚动可用（自动滚动不支持，明确提示）。

## M7 · 发布（第 13–14 周）

**做**

- 签名与公证（macOS notarization、Windows 代码签名）。
- 自动更新（可选、默认关闭、签名校验）。
- 崩溃恢复、日志轮转、`doctor --check-storage`。
- 安装包（dmg / msix / AppImage）、首次运行引导视频或动图。
- 文档：快捷键速查卡、滚动截屏原理说明、FAQ。

**门禁 G7**

- 三平台各安装一次，从零到成功截图 ≤ 2 分钟（含权限）。
- 连续 8 小时挂机（100 次截图 + 10 次滚动），内存无泄漏（RSS 增长 < 10%）。
- 卸载后无残留（除用户主动保留的历史）。

## 依赖与顺序

```
M0 ──► M1 ──► M2 ──► M3 ──► M4 ──► M5
                       │             │
                       └──► M6 ◄─────┘
                              │
                              ▼
                             M7
```

- M4 依赖 M1（长图要能标注）和 M3（历史要能存）。
- M5 依赖 M4 的内核接口不变（`stitch` 是纯函数，抓帧策略可换）。
- M6 的 OCR 与 M4/M5 无耦合，可以并行。

## 明确的时间风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| macOS 权限与签名流程 | 阻塞 M0/M7 | 第一周就把 TCC 与公证脚本跑通 |
| Windows 后端（无 mac 上的测试机） | M5 延期 | 先用 WGC 官方示例验证可行性，再排期 |
| 滚动基准集制作 | M4 延期 | 第 5 周就开始录，不等到 M4 |
| 标注的"手感"打磨无上限 | 无限延期 | 门禁只认可测项，手感靠 M3 的 3 天自用 |
