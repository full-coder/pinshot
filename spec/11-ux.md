# 11 · 交互与快捷键

## 1. 快捷键总表

mac 上 `Ctrl` → `⌘`。所有快捷键可在设置里改；下表是默认值。

### 全局（应用未聚焦时也生效）

| 键 | 动作 |
| --- | --- |
| `F1` | 开始截图 |
| `F3` | 贴图（剪贴板 → 置顶窗口） |
| `Shift+F3` | 显示 / 隐藏全部贴图 |
| `Ctrl+Shift+S` | 快捷保存上一次截图（不弹窗） |

> macOS 上 `F1`/`F3` 默认被系统亮度/调度占用，首次运行检测冲突并提示改用
> `⌘⇧1` / `⌘⇧3`（仍可手动指定 `F1`）。

## 2. 状态与反馈

| 状态 | 视觉 | 提示 |
| --- | --- | --- |
| 进入截图 | 全屏冻帧 + 半透明遮罩 + 十字光标 | 选区左上角显示尺寸 |
| 已选区 | 选区明亮，外部 50% 遮罩 | 顶部工具条淡入（120 ms） |
| 标注中 | 光标变成对应工具 | 工具栏当前工具高亮 |
| 滚动中 | 选区缩成进度条 + 实时长图预览 | 「已捕获 3 屏 · 按 Esc 停止」 |
| 滚动失败 | 长图 + 接缝高亮 | 「第 2 段可能错位，改用手动滚动？」 |
| 导出中 | 选区边框闪一下 | 无模态；失败才提示 |
| 权限缺失 | 引导卡片 | 「需要屏幕录制权限──点这里打开设置」 |

## 3. 视觉语言

- 一个强调色：`#E8452C`（与工具条选中、序号标注、进度条统一）。
- 中性灰阶，遮罩 50% 黑，工具条 `rgba(28,28,30,0.92)` + 12 px 圆角 + 8 px 内边距。
- 工具条图标线性 1.5 px，24×24；选中态用强调色描边 + 12% 强调色底。
- 尺寸标签用等宽数字字体（`ui-monospace`），避免数字跳动导致的重排。
- 动效只用于"出现/消失"（120 ms ease-out），不做弹跳。

## 4. 空态与边界

| 场景 | 处理 |
| --- | --- |
| 历史为空 | 插图 + 「按 F1 截第一张图」 |
| 剪贴板无内容时按 F3 | 托盘气泡「剪贴板里没有可贴的内容」，不弹窗 |
| 剪贴板是 10 MB 文本 | 截断到 4000 字符并提示「已截断」 |
| 屏幕权限被拒 | 引导卡片，不重复弹窗（每天最多一次） |
| 滚动时页面完全不动 | 3 帧后停止并提示「页面似乎不能滚动」 |
| 滚动时高度超限 | 停止 + 「已截断，可在设置里调高上限」 |
| 磁盘满 | 导出失败提示路径与剩余空间；历史继续记录（只是不能保存 blob）→ 实际做法是先检查空间，不足则拒绝并提示 |

## 5. 文案规范

- 面向动作，不面向实现：「在系统设置里允许屏幕录制」而不是「TCC 授权失败」。
- 每条错误都包含**下一步**：能点的地方给按钮，不能点的给路径。
- 不用「错误代码 -3801」这种；技术细节写日志，UI 只给可执行信息。
- 中英双语；文案集中在 `locales/`，不在组件里硬编码。

## 6. 可访问性

- 所有图标按钮有 `aria-label`；工具条可用键盘 `Tab` 走通。
- 对比度：正文 ≥ 4.5:1，工具条图标 ≥ 3:1。
- 不依赖颜色单独传达状态（选中态同时有描边与底色变化）。
- 尊重「减少动态效果」系统设置（关闭淡入）。
