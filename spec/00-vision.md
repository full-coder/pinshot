# 00 · 产品定位

## 1. 一句话

**PinShot 是一个「按下热键之后不需要思考」的截图工具**：选区、标注、复制或贴到屏幕上，
全程不离开键盘；需要长图时，它自己滚、自己拼。

## 2. 问题

截图是每天发生几十次的动作，但常见工具会让用户在一半的步骤上停顿：

- 「这页太长，我分三张截，然后在画图里拼起来」——占掉 3 分钟。
- 「截完想留着对比，结果只能贴在聊天窗口里，切走了就没了」——贴图工具缺失。
- 「我要把这一段发给同事，但里面有手机号和 token」——标注工具没有马赛克，只能换工具。
- 「这次截的图在哪？昨天那张呢？」——没有历史，只能翻 Finder。

这四件事对应四个功能：**滚动截屏、贴图、标注、历史**。Snipaste 把后三个做得很好，
第一个至今没做；其他工具（PixPin、PowerToys、CleanShot X）各有取舍，没有一个把四件事都做顺。

## 3. 目标用户

| 用户 | 典型动作 | 关键诉求 |
| --- | --- | --- |
| 开发者 | 贴报错、贴日志、贴 PR diff、给 issue 配图 | 快、不打断思路、能贴住不消失 |
| 产品 / 设计 | 截长页面、圈重点、对比两版 | 滚动截屏、精准标注、多图并排 |
| 客服 / 运营 | 截后台、打码、发群里 | 马赛克、序号、一键复制 |
| 写文档的人 | 整页保存、图文混排 | 长图质量、命名与归档 |
| 自动化用户 | 定时截图存档、CI 里截 UI | 无 GUI 调用、结构化输出 |

## 5. 差异化（三条，按优先级）

1. **滚动截屏做成默认能力，而不是隐藏功能。**
   - 选框拉到底部时，边缘出现「向下滚动」提示 → 一次点击进入滚动模式；
   - 自动模式：程序向目标窗口注入滚轮事件，稳定后抓帧，自己拼；
   - 手动模式：你滚你的，它连续抓帧并实时预览已拼出的长图（对手感要求高、或滚动事件被拦的页面）；
   - 窗口级模式：按窗口 ID 抓帧，**其他窗口盖在上面也不影响**。
2. **贴图是窗口，不是剪贴板。** 可缩放、旋转、调透明度、鼠标穿透、分组、隐藏/恢复，
   语义严格区分「关闭 / 隐藏 / 销毁」（见 `06-pin-window.md`），不做含糊的实现。
3. **可脚本化。** `pinshot snip --area 0 0 800 600 -o clipboard --json` 返回结构化结果，
   能被 shell、CI、快捷指令调用；核心逻辑在 CLI 里就能跑，不依赖 GUI。

## 6. 非目标

- 不做录屏 / GIF（P3 之后再评估，需要另一套编码管线）。
- 不做云同步、账号体系、社交分享。
- 不做图片编辑器：没有图层、没有滤镜、没有导出为 PSD。
- 不做 PDF 整页截取（滚动截屏能覆盖 90% 的场景）。
- 不联网。唯一的网络行为是可选更新检查，默认关闭。

## 7. 设计原则

1. **一次截图 ≤ 3 次按键。** 热键 → 拖框 → 回车。任何超过 3 步的常规路径都算设计缺陷。
2. **Esc 永远能退出当前状态。** 每层（选区 / 标注 / 贴图 / 滚动）都有独立的退出语义，
   且不会误伤下一层。
3. **冻帧优先。** 进入截图模式的瞬间把屏幕定格成一张位图，之后所有交互都基于这张图，
   不跟实时画面赛跑。这既保证了标注精度，也让上层可以用普通 GUI 技术实现。
4. **像素就是像素。** 所有几何量以物理像素存储，与缩放比（1x / 2x / 1.5x）解耦；
   只在显示与导出时换算，且换算只在一个模块里发生。
5. **不打断。** 不弹模态框、不抢焦点、不写系统日志以外的位置；贴图窗口永远不抢键盘焦点，
   除非用户在它上面按了空格。
6. **本地优先。** 截图默认只落在本机磁盘与剪贴板。没有账号、没有遥测上传；
   需要分享时用户自己按复制。

## 8. 成功度量

| 指标 | 目标 | 测量方式 |
| --- | --- | --- |
| 热键 → 覆盖层可见 | p95 ≤ 100 ms | 内置打点，`pinshot bench overlay` |
| 选区 → 剪贴板 | p95 ≤ 60 ms | `pinshot bench export` |
| 标注笔迹延迟 | p95 ≤ 16 ms（单帧） | `pinshot bench annotate` |
| 滚动截屏成功率 | ≥ 90%（20 个真实页面基准集） | `spec/10-testing.md` 的基准集 |
| 滚动截屏单页耗时 | ≤ 1.6 s / 1000 px 页面高度 | 同上 |
| 常驻内存（无贴图） | ≤ 60 MB | Activity Monitor |
| 每张 4K 贴图额外内存 | ≤ 40 MB | 同上 |
| 崩溃率 | < 0.1% 会话 | 本地崩溃日志统计（不外传） |
| 日常替代率 | 作者本人连续 14 天不用其他截图工具 | 手动记录 |
